# Trance Kafka Website

A modern, responsive website for Trance Kafka featuring smooth CSS animations and a clean design. The site showcases event information, promoter details, and provides multiple ways for visitors to get in touch.

## Features

- **Responsive Design**: Fully responsive layout that works across all devices
- **CSS Animations**: Smooth, performant animations and transitions throughout the site
- **Multi-page Layout**: Organized pages including home, about, promoters, and contact

## Technology Stack

- **Frontend**: HTML5, CSS3 (with animations)
- **Web Server**: NGINX
- **Hosting**: Raspberry Pi 5
- **Domain**: Duck DNS (remote access)

## Deployment

The website is hosted on a Raspberry Pi using NGINX web server with Duck DNS for remote accessibility:

```bash
# Access the live site
https://www.trancekafka.se
```

### Server Configuration

- Server: Raspberry Pi
- Web Server: NGINX
- DNS Service: Duck DNS (for dynamic DNS)
- Domain: trancekafka.se
